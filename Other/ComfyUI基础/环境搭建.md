# 为什么学习 ComfyUI？

Stable Diffusion WebUI 更像一个"图片生成软件"。

用户修改几个参数，就可以生成图片。

而 ComfyUI 更像一个可视化编程环境。

它把 Stable Diffusion 的整个生成过程拆解成一个个节点，让每一步都可以自由控制。

因此：

> ComfyUI 的本质不是绘图软件，而是一套 AI 图像生成工作流（Workflow）开发平台。

---

# 为什么本课程选择 ComfyUI？

未来几乎所有先进工作流都会基于 ComfyUI，例如：

- Flux
    
- ControlNet
    
- IPAdapter
    
- AnimateDiff
    
- 视频生成
    
- AI 漫剧
    

学习 ComfyUI，相当于学习整个 AI 图像生成系统的架构。

# 创建虚拟环境

进入项目目录：

```bash
cd ~/AI/ComfyUI
```

创建虚拟环境：

```bash
python3.11 -m venv venv
```

激活：

```bash
source venv/bin/activate
```

终端前面出现：

```text
(venv)
```

说明已经进入 ComfyUI 的专属 Python 环境。

---

# 启动 ComfyUI

目前（Mac M1 环境）：

```bash
python3.11 main.py --cpu
```

浏览器访问：

```text
http://127.0.0.1:8188
```

即可进入 ComfyUI。

---

# 停止 ComfyUI

终端：

```text
Ctrl + C
```

退出虚拟环境：

```bash
deactivate
```

---

# 为什么使用 Python 虚拟环境？

Python 的不同项目往往依赖不同版本的软件包。

例如：

项目 A：

- torch 2.8
    

项目 B：

- torch 2.10
    

如果安装到系统 Python 中，很容易互相影响。

因此：

每个 AI 项目都应该拥有自己的虚拟环境。

这与 Android 项目的 Gradle 依赖管理思想类似。
